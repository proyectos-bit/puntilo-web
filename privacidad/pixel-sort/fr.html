Politique de confidentialité de Pixel Sort

Dernière mise à jour : 9 octobre 2026

Pixel Sort est un jeu Android publié par Puntilo Studio (paquet com.puntilo.pixelsort). Cette page explique quelles données sont traitées lorsque vous jouez, pourquoi et qui les reçoit.

Données qui restent sur votre appareil

Le jeu enregistre sur votre téléphone votre progression, vos pièces, votre profil (avatar et, si vous en saisissez un, un nom de 16 caractères au plus) et vos réglages. Il n'y a ni compte utilisateur ni copie dans le cloud : ces données ne quittent pas l'appareil et sont supprimées lorsque vous désinstallez le jeu.

Publicités (Google AdMob)

Pixel Sort affiche des publicités via le SDK Google Mobile Ads (AdMob). Pour diffuser et mesurer les publicités et prévenir la fraude, ce SDK collecte et envoie à Google : l'adresse IP (dont est déduite une localisation approximative), les interactions avec l'application (lancements, appuis sur les publicités), des données de diagnostic, l'identifiant publicitaire Android et l'identifiant d'ensemble d'applications. Les données sont chiffrées en transit (TLS).

Comment Google traite ces données : Comment Google utilise les informations provenant de sites ou d'applications qui utilisent ses services et les Règles de confidentialité de Google. Ce que déclare le SDK : Play data disclosure du SDK Google Mobile Ads.

Vous pouvez réinitialiser ou supprimer l'identifiant publicitaire et limiter les publicités personnalisées dans les paramètres Android (Google > Annonces).

Statistiques (Google Analytics for Firebase)

Pour savoir quels niveaux sont difficiles et combien de jeu il reste aux joueurs, Pixel Sort utilise Google Analytics for Firebase. Il envoie trois notifications par tentative de niveau : commencée, gagnée ou perdue, avec le numéro du niveau, s'il s'agit d'une répétition et le nombre de sauvetages utilisés. Le SDK ajoute ses événements automatiques de session et de première ouverture, un identifiant d'instance de l'application et une localisation approximative déduite de l'adresse IP. Il n'envoie pas l'identifiant publicitaire pour les statistiques, ni votre nom de profil, ni vos pièces. Les données sont chiffrées en transit (TLS).

Dans l'Espace économique européen, au Royaume-Uni et en Suisse, ces statistiques suivent votre choix dans le formulaire de consentement (modifiable dans Paramètres > Confidentialité) : si vous n'acceptez pas, seules des notifications sans identifiant sont envoyées. Ce que collecte le SDK : données collectées par Google Analytics for Firebase.

Votre consentement

Dans l'Espace économique européen, au Royaume-Uni et en Suisse, le jeu vous demande votre choix concernant les publicités personnalisées avant d'en afficher (plateforme de messagerie utilisateur de Google, UMP). Votre choix est enregistré sur l'appareil et vous pouvez le modifier depuis le bouton « Confidentialité » des réglages du jeu.

Réglages à distance

Au démarrage, le jeu télécharge depuis ce site un petit fichier de réglages (fréquence des publicités et économie du jeu). C'est un téléchargement ordinaire : le serveur qui héberge ce site voit l'adresse IP de la requête, comme pour toute page web ; le jeu n'envoie aucune autre donnée.

Mineurs

Pixel Sort ne s'adresse pas aux enfants de moins de 13 ans et ne collecte pas sciemment de données les concernant.

Modifications et contact

Si cette politique change, la nouvelle version sera publiée ici avec sa date. Pour toute question : contacto@puntilo.com.
